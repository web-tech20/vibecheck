## ✨ What is VibeCheck?

VibeCheck transforms your voice into an **immutable proof on the Solana blockchain**. Speak, get AI-powered emotion analysis, and anchor your words forever — with a downloadable NFT-style badge.

### 🔥 Why it matters
- 🎙️ **Voice is identity.** Your words deserve to be provable.
- ⛓️ **Blockchain ensures integrity.** Once anchored on Solana, your proof is permanent.
- 🤖 **AI understands emotion.** ElevenLabs transcribes + analyzes your vibe.
- 🎖️ **You leave with a badge.** A verifiable, shareable proof of your voice.

## 🛠️ Tech Stack

| Technology | Role |
|-----------|------|
| **ElevenLabs** | Speech-to-Text transcription + emotion analysis |
| **Solana (Devnet)** | On-chain anchoring via Memo program |
| **SHA-256** | Cryptographic fingerprint of your voice |
| **Express.js** | Backend API server |
| **Vercel** | Instant deployment |
| **Web Audio API** | In-browser recording |
| **CSS Glassmorphism** | Premium dark UI |

## 🏗️ Getting Started

```bash
git clone https://github.com/yourname/vibecheck
cd vibecheck
npm install
cp .env.example .env
# Fill in your ElevenLabs and Solana keys
node server.js
# Open http://localhost:3000
```

---

## 🔑 Environment Variables

| Variable | Description |
|----------|-------------|
| `ELEVENLABS_API_KEY` | Your ElevenLabs API key |
| `SOLANA_PRIVATE_KEY` | JSON array of your Solana wallet secret key |
| `SOLANA_RPC_URL` | Solana RPC endpoint (default: devnet) |
